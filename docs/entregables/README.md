# Entregables del Proyecto - Academit

En este directorio se centralizan los documentos y modelos de entrega del proyecto **Academit** (TP Integrador - Taller 3):

## Entregable 1: Análisis del Sistema
- [Entregable 1: Análisis y Requisitos](entregable-1-analisis.md): Descripción del problema, objetivos institucionales, actores, catálogo de 45 requisitos funcionales (RF01 a RF45) y matriz de reglas de negocio (RN01 a RN14).

## Entregable 2: Modelos y Diagramas UML
Archivos y especificaciones correspondientes a los modelos del sistema (con diagramas PlantUML):

- [Casos de Uso](entregable-2/casos-de-uso.md): Actores y flujos principales de casos de uso por módulo.
- [Diagrama de Clases](entregable-2/diagrama-de-clases.md): Modelo de dominio y entidades del sistema.
- [Diagramas de Secuencia](entregable-2/):
  - [Secuencia de Calificación](entregable-2/secuencia-calificacion.md): Flujo de carga y registro de notas docentes.
  - [Secuencia de Inscripción](entregable-2/secuencia-inscripcion.md): Flujo de inscripción a cursos y control de cupos.
  - [Secuencia de Pagos](entregable-2/secuencia-pagos.md): Flujo de cobro de cuotas y emisión de comprobantes.
- [Diagrama Entidad-Relación (DER)](entregable-2/der.md): Esquema de base de datos relacional para PostgreSQL.
