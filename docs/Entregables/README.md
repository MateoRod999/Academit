# Diagramas UML - Academit

En este directorio se almacenan los archivos fuente en formato PlantUML (`.puml`) correspondientes a los modelos y diagramas del sistema:

- **Casos de Uso**: Actores y flujos principales por módulo.
- **Diagrama de Clases**: Modelo de dominio y entidades del sistema.
- **Diagramas de Secuencia**: Interacción y orquestación de operaciones clave (inscripción a cursos, cobro de cuotas, carga de calificaciones).
- **Diagrama Entidad-Relación (DER)**: Esquema de base de datos relacional para PostgreSQL.
